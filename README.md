One line, under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation.

> I'm on vacation. My inbox is now handled by an intern — an AI, who is also on vacation.

`main.ts` writes that single line to `/output/entry.txt` (no trailing newline). Built for the [make.fun bounty](https://make.fun/c/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d).
